Feasibility notes

What this experiment is measuring for a motion-game prototype.

  • Peak magnitude is reliable enough for “did they swing?” events on modern phones.
  • Direction from a single accel peak is coarse; gyro integration or relative orientation helps for aim.
  • iOS Safari requires a user gesture + DeviceMotionEvent.requestPermission() over HTTPS.
  • Desktop browsers usually lack motion sensors — use Simulate to exercise detection logic.
